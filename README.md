# PassOP – Password Manager

PassOP is a secure full-stack web application that allows users to store, view, and manage their credentials in one centralized platform. The app is designed with usability, performance, and security in mind, making it easy for users to manage passwords safely.

---

## Features

- **Add, Edit, Delete Credentials:** Easily manage multiple accounts and passwords.
- **Secure Storage:** All credentials are stored securely in the backend database.
- **User-friendly Interface:** Clean and responsive single-page interface.
- **Search Functionality:** Quickly find credentials by platform or username.
- **Organized View:** View all saved credentials in a structured and organized format.

---

## Tech Stack

- **Frontend:** React, Tailwind CSS  
- **Backend:** Express.js  
- **Database:** MongoDB
